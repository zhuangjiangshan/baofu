# 是男人就下100层｜暴富版

一个可以直接上传到 GitHub Pages 的静态网页小游戏。

## 玩法

- 主角头顶名字是「暴富」。
- 目标：一路向下，到达第 100 层。
- 楼板和道具包含股市元素：基金涨%、基金亏%、牛市、熊市、涨停、跌停、分红、加杠杆、打新股、暴雷、破产等。
- 加杠杆后，收益和亏损都会翻倍。

## 操作

- 左移：键盘 `←` 或 `A`
- 右移：键盘 `→` 或 `D`
- 开始/暂停：空格
- 手机端：底部按钮控制

## 上传 GitHub Pages

1. 新建一个 GitHub 仓库，比如 `baofu-100-floor-game`。
2. 把 `index.html`、`styles.css`、`game.js` 上传到仓库根目录。
3. 进入仓库 `Settings` → `Pages`。
4. `Build and deployment` 选择：
   - Source：`Deploy from a branch`
   - Branch：`main` / `/root`
5. 保存后，等待 GitHub 生成预览地址。

## 本地预览

直接双击 `index.html` 即可运行。
